## 📂 Repository Structure
Developed with a "Clear & Categorized" philosophy to ensure maintainability and discoverability.

```text
├── projects/           # High-fidelity, full-feature applications
├── games/              # Interactive game logic and state management
├── components/         # Reusable UI components and animations
├── learning-archives/  # Fundamental notes and daily coding challenges
├── docs/               # System design and architecture documentation
├── .github/            # Open source collaboration templates
└── package.json        # Centralized engineering tooling
```
