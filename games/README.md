# Interactive Games 🎮

Explore a collection of interactive games built with Vanilla JavaScript logic. These projects focus on state management, game loops, and responsive interaction design.

## 📁 Game Index

### [Classic Snake](./classic-snake)
- **Logic:** 2D grid navigation, collision detection, and dynamic speed scaling.
- **Stack:** HTML5 Canvas, JavaScript Game Loop.

### [Tic-Tac-Toe](./tic-tac-toe)
- **Logic:** Minimax algorithm (basic) / Winning pattern matching and turn-based state.
- **Stack:** CSS Grid, JavaScript Event Delegation.

---

## 🏗️ Technical Focus
- **State Engines:** Managing complex, rapidly changing game states.
- **Input Handling:** Smooth keyboard and touch control integration.
- **Visual Feedback:** CSS transitions and animations for game events.
