# Projects Collection 🚀

This directory contains high-fidelity, full-feature web applications built using Vanilla JavaScript and modern CSS architectures. Each project is designed to solve a specific problem or demonstrate advanced frontend concepts.

## 📁 Portfolio Index

### [Movie Database Explorer](./movie-database)
- **Concept:** Asynchronous data management with external REST APIs.
- **Key Skill:** `Async/Await`, `fetch`, Grid Layouts, UX states.

### [E-Commerce State Manager](./e-commerce-cart)
- **Concept:** Complex state synchronization and persistent data.
- **Key Skill:** `LocalStorage`, dynamic pricing logic, logic-heavy UI.

### [Task Management System](./task-manager)
- **Concept:** Classic CRUD operations and event orchestration.
- **Key Skill:** DOM manipulation, keyboard accessibility.

### [Authentication Flow](./authentication-flow)
- **Concept:** Security-first UI design and form validation.
- **Key Skill:** Regex, visual feedback loops, security patterns.

---

## 🛠️ Project Standards
All projects in this directory follow these engineering mandates:
1. **Responsive Design:** Mobile-first approach.
2. **Semantic HTML:** Proper use of structural tags.
3. **Optimized JS:** Minimal DOM thrashing and clean event delegation.
